GESTALT Browser Desk Privacy Policy

Last updated: November 13, 2026

What the extension stores

GESTALT Browser Desk stores bookmarks, bookmark titles, URLs, and timestamps locally in the browser’s extension storage when you choose to save or import them. It does not sell, profile, advertise against, or transmit this data.

Browser access

The tabs permission is used only to read the active tab’s title and URL after you choose “Save current tab” or use the context-menu action. The storage permission keeps your local bookmark desk available between sessions. Context menus adds the optional “Save page to GESTALT” action.

Optional web app URL

You may configure a Gestalt web app URL. The extension does not send bookmarks there automatically. It opens that URL only when you choose “Open web app.”

Contact

For questions or reports, use the project repository at github.com/numbpill3d/gestalt.
